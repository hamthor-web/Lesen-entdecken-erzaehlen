# Alter Vorläufer – durch Spielesammlung ersetzt

Dieses Repository enthält einen älteren Stand von **Lesen, entdecken, erzählen** mit Fußballgeschichten, Parkgeschichten und „Finde den Fehler“.

## Aktuelle Weiterentwicklung

Die aktuelle Entwicklung der großen App und ihrer Webfassung liegt hier:

**[Spielesammlung für Lesefreude](https://github.com/hamthor-web/Spielesammlung-fuer-Lesefreude-)**

Das Android-Projekt liegt dort im Unterverzeichnis `android-app`.

Dieses ältere Repository wird als historischer Stand aufbewahrt und nicht weiterentwickelt. Es ist nicht die maßgebliche Quelle der aktuellen Android-App. Die bestehenden Spieldateien bleiben unverändert erhalten.

Die Archivierung wurde am 29.10.2026 von Heike beauftragt. Ob die technische GitHub-Archivierung bereits abgeschlossen ist, zeigt der Archivhinweis von GitHub am Repository.
